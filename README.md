# AI×Coding for VSCode

AI×Coding 旨在通过 AI 助力编程，提高开发效率和代码质量。它集成了智能问答、代码生成、代码解释、代码检查、自动生成注释、编写测试和代码自动补全等多项功能。

## 功能概述

- **智能问答**：提供即时编程问题解答和技术支持。
- **代码生成**：根据用户输入的描述自动生成代码片段。
- **解释代码**：帮助理解复杂代码逻辑。
- **检查代码**：分析代码质量，提供优化建议。
- **生成注释**：自动为代码添加注释，提高代码可读性。
- **编写测试**：自动生成单元测试，确保代码质量。
- **代码自动补全**：智能补全代码，提高编码速度。
- **超强编程 AI 智能体**：通过自然语言与用户交流，直接读写工作区文件，执行终端命令来完成编程任务。

## 使用指南

### 智能问答

- 在插件面板输入框中输入问题，点击“发送信息”按钮即可。

### 解释代码、检查代码、生成注释、编写测试

- 在编辑器中选择要解释、检查、生成注释或编写测试的代码。
- 点击插件面板中的相应按钮即可。

### 代码补全

- 在编辑器中正常进行编码
- 输入代码时，插件会自动提示可能的代码补全选项。
- 点击'Tab'按钮接受建议的代码补全。
